AUDISK BY KIRAA - PREBUILT VENCORD BUNDLE
============================================

This bundle installs a prebuilt Vencord runtime containing the Audisk userplugin.

Project: https://github.com/AkiyamaKira2003/auto-discord-task
Plugin: Audisk
Command: /audisk
Maintainer: Kiraa (AkiyamaKira2003)
Discord profile in the dashboard: akiyamakira2003

INSTALL
-------
Run INSTALL.cmd and follow the prompts. After Discord restarts, open Vencord Plugins and search for Audisk.

The bundle path is intended for users who want a prebuilt runtime. The devbuild installer under tools\audisk-devbuild-installer is preferred when you want Vencord itself to remain a normal git checkout that can be rebuilt and updated.

CONTROLS
--------
/audisk action:start
/audisk action:stop
/audisk action:status
/audisk action:pause
/audisk action:resume

The floating dashboard provides the same start/stop and pause/resume controls plus Quest progress and logs.
